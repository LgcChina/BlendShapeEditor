# LGC 形态键编辑器 v1.6.1

Unity 2022.3 编辑器工具，用于删除、重命名、新建空形态键、混合形态键及调整形态键上限。
入口：**LGC > 形态键编辑器**。无需 VRCFury、Modular Avatar 或 VRChat SDK。

## 通过 VCC / ALCOM 安装

合集地址：<https://lgcchina.github.io/LGC-VRC-Packages>。
在 VCC / ALCOM 添加该合集，然后为项目安装 **LGC 形态键编辑器**（`com.lgcchina.blend-shape-editor`）。Unity 编译后，从 **LGC > 形态键编辑器** 打开。

需要 Unity **2022.3**；不依赖 VRChat SDK、VRCFury 或 Modular Avatar。自动组合窗口已在 Unity 2022.3.22f1 验证。
包源码与版本发布：<https://github.com/LgcChina/BlendShapeEditor>。

从 Assets 手动版迁移时，VPM 迁移配置仅替换原工具的 **Editor** 子目录，保留 `Meshes` 等生成文件与其他目录。若之前复制过其他脚本副本，请移除重复代码后等待 Unity 编译。生成网格继续保存到 **Assets** 下，不写入包目录。

## 安装与使用

1. 推荐通过上述 VCC / ALCOM 合集安装。手动安装可将发布 ZIP 解压为 Assets 下的“形态键编辑器”文件夹，保留 `.meta`，等待 Unity 编译；请勿同时保留两份工具脚本。
2. 每次打开窗口时手动将普通场景实例的 Body 或其他 **SkinnedMeshRenderer** 拖入“目标网格”，不会自动绑定 Unity 当前选中的物体。左右宽度按 60% / 40% 随窗口调整。左侧列表使用窗口剩余高度，右侧各操作区域独立分框，增大内边距和区块间距，并可整体滚动。
3. 形态键按原列表顺序每 **20 项一组**，默认展开第一组；可以单独折叠，也可以“全部展开 / 全部折叠”。这只是面板分组，不新增或改变网格内的形态键。
4. 搜索时自动展开包含匹配项的组，清空搜索恢复原折叠状态。“全选”选择所有符合当前搜索和“显示待删除”筛选的项目，包括折叠组内的项目；“取消选择”清空所有选择。
5. 在列表直接重命名或填写“形态键上限”；左侧勾选后可在右侧批量删除、恢复、设置上限或混合。默认显示待删除项，删除仅作标记，应用前可恢复。
6. 创建空形态键：填写名称并点击“新建空形态键”。它包含一个权重 100、顶点 / 法线 / 切线位移为零的帧。
7. 混合：勾选源项、填写各行“混合权重 %”、输入新名称并点击“混合所选为新形态键”。默认保留源项，配方固定在创建时，后续改动源草稿不会回改已经创建的结果。
8. 点击“解锁预览”加载临时网格后拖动预览滑条。滑条初始锁定，不会因误拖自动加载网格；点击“锁定预览”恢复原网格和权重。
9. 首次点击“应用并保存新网格”生成独立 Mesh 并替换目标；同一目标、窗口未关闭期间继续应用会覆盖本次生成的同一个 Mesh，保留文件路径和 GUID。按需自行保存场景。保存期间禁止再次点击，完成后冷却 3 秒。

## 形态键上限：以 Unity 权重 100 为基准

默认 **100**，范围 **−1000～1000**。界面直接输入熟悉的 Unity 权重数值，内部按“输入值 ÷ 100”缩放形态键数据。

面板说明：形态键上限 100 为基准：例如填 62，生成后拉到 100 就是到 62 的效果；填 180 就是突破上限到 180 的效果。范围 −1000～1000，负数将反向执行顶点。

| 形态键上限 | 生成后拉到 100 的效果（单帧线性形态键） |
| --- | --- |
| 62 | 相当于修改前拉到 62 |
| 100 | 保持原效果 |
| 180 | 相当于修改前拉到 180 |
| 0 | 不产生变形 |
| −100 | 原效果反向 |
| 1000 | 原效果的 10 倍 |

例如原眨眼拉到 62 就是想要的闭合程度，将形态键上限填为 62，应用后常用权重仍是 0～100。
批量上限是直接设置所选项，不是在当前草稿上再次相乘；预览滑条和混合权重仍使用各自的 0～100 范围。
再次应用以最新网格为基准，修改会叠加：连续两次应用 180，最终为最初的 3.24 倍。

这是缩放网格变形数据，不是运行时参数钳制。其他脚本仍可传入超过 100 的权重。
多帧形态键保留各帧权重并统一缩放帧位移；如果原多帧变化不是线性的，结果不等于重新采样原曲线在该输入权重处的形状。
负值反转相对基础形状的位移，不保证自然的反向效果，请检查穿模和光照。

## 混合与数据保留

- 混合结果是各源形态在指定混合权重和形态键上限下的变形之和，不做平均或自动归一化，生成一个权重 100 的新帧。
- 多帧源按帧权重分段插值；缺少零权重帧时以零位移为零点，超出端点时沿最近区间外推。
- 原形态键保留原帧权重，统一缩放顶点、法线和切线位移，不强制转换为单帧。
- 克隆源 Mesh 再重建形态键，保留顶点数据、UV 通道维度、子网格拓扑、骨骼权重与绑定姿态。
- 输出 Mesh 及 Renderer 包围盒会适当扩展；骨骼动画与极端组合仍需实测。
- 空名称、首尾空白、控制字符、重名、不可读网格等情况会阻止生成，错误在面板显示。

## 模型2自动组合窗口

点击主工具中的 **预览模型2**，模型2会自动停靠在主工具右侧，组成同一 Unity 窗口中的左右分栏。首次组合主工具约占 2/3、模型2约占 1/3，实际比例受各面板最小宽度限制；可以拖动中间分隔线调整。

- 已经是左右组合时，再次点击只激活已有面板，保留分隔线位置，不新增窗口。
- 已拖入的模型、预览数值、同步开关与编辑草稿保留。两个面板仍有独立标签，可以分别关闭或拖出。
- 主工具单独浮动时，会按组合所需宽度扩大窗口。若主工具已经停靠在其他 Unity 布局中，不主动扩大整个编辑器；空间不足会在模型2面板提示，可放大主工具区域后重试或手动拖动标签停靠。
- 自动分栏使用 Unity 内部停靠接口，已在 Unity 2022.3.22f1 验证。其他版本如接口不兼容，会保留普通模型2窗口并显示手动停靠提示。

## 预览、保存与两种恢复

预览使用临时 Mesh，不保存资产。锁定预览、修改形态定义、切换目标、保存场景、进入运行、重编译或关闭窗口时，恢复预览前的网格、权重和包围盒。
预览权重与人物原有权重独立；修改形态定义后会锁定滑条，需要重新点击“解锁预览”。首次加载大网格可能短暂等待，后续拖动只更新权重。测试时请避免 Animator 或其他预览争用权重。

输出默认保存到工具的 **Meshes** 子目录，首次生成前，点击“选择文件夹”打开系统文件夹选择窗口，可选择当前项目 Assets 或其子目录，路径自动转换为 Unity 资源路径；选择项目外目录时保留原路径并在面板提示。首次生成后，本次目标的输出文件和目录固定，选择按钮禁用；若要另存其他目录，请结束本次目标会话后重新选择。点击“定位输出文件夹”在 Unity Project 窗口选中并高亮目录；默认目录尚未创建时会提示，应用保存后再定位。生成 Mesh 内部名称与文件名一致，采用本次拖入时的原网格名称加本机日期和时间，例如 `Body_261110_214830.asset`。首次生成同秒重名时自动追加序号，不覆盖源 FBX、源 Mesh 或之前会话的文件；后续应用仅覆盖本次创建的输出。
应用时按源索引迁移保留项原权重，新形态键默认为零。网格替换和本次输出的内容覆盖支持 Ctrl+Z / Ctrl+Y，记录 Prefab 覆盖并标记场景修改；Undo 不删除输出资产。恢复原始网格后继续应用仍更新本次输出；切换目标、清空目标或关闭窗口结束该输出会话，下一次创建新文件。若本次输出被手动删除，恢复有效网格后再应用会重新创建输出。

## 完整生成与稀疏生成

“恢复到原始网格-未修改”按钮下方提供 **稀疏生成** 复选框，默认不勾选。

- 不勾选：保留形态键的顶点、法线与切线位移，使用完整生成。
- 勾选：保留顶点位移，将法线和切线位移清零，可能减小网格文件体积，但可能缺失光照、阴影、高光和法线贴图细节；勾选后在下方显示提示。
- 预览和应用均使用所选生成方式。已经稀疏应用后，当前编辑源不再含被清除的数据；取消勾选不会自动找回这些数据，需要先恢复原始完整网格再处理。

## 原始网格与 FBX 备用恢复

**恢复到原始网格-未修改**：恢复本窗口本次拖入目标时记录的 Mesh、原权重和包围盒，支持 Undo。首次点击变红，提示“此操作不会删除已生成的文件”，5 秒内再次点击才恢复，超时自动取消；继续编辑或切换其他操作会取消确认。

当前编辑网格或生成文件被误删后，工具禁用依赖当前网格的编辑和保存，仍保留原始网格恢复入口。恢复优先使用拖入时的原始资源；如果该资源也被删除，则将独立的初始快照按当前输出目录另存为新 Mesh，再恢复到场景目标，不会在原文件路径重建或删除其他已生成文件。快照来自拖入时的网格，不包含之后的编辑。

关闭窗口先退出预览、恢复预览前网格，然后清空目标、原始与当前网格引用、原权重、编辑草稿和临时快照。重新打开时目标为空，需要重新拖入。已生成文件和已应用的网格保持不变。

独立快照仅用于本次窗口会话，切换目标或关闭窗口会释放，不是永久备份；请保留原资产或场景备份。工具不会自动寻找原始 FBX，选入时已经修改过的网格仍会成为这次恢复基准。重新读取当前网格和 Undo / Redo 不会重设拖入时的恢复基准。

**恢复默认参数**：只清除尚未应用的草稿，恢复当前编辑源网格的形态键列表；恢复批量上限为 100、新名称为 NewShape。已保存的网格和输出路径保留。第一次点击按钮变红，**5 秒内**再次点击才执行；超时自动恢复普通按钮，继续编辑、切换目标或切换预览也会取消确认，无弹窗。

**FBX 备用恢复**：当前网格或初始快照丢失时，在右侧“FBX 备用恢复”区域使用。

1. 点击“自动查找 FBX”，按 Prefab 来源链、原网格资源路径、父级 Animator.avatar 的顺序查找；也可手动将原 FBX 拖入字段。
2. 在 FBX 子资源中按物体名称 / 原网格名称等寻找唯一匹配项；没有唯一匹配时，从列表明确选择，不自动取第一个。
3. 恢复前核对蒙皮网格和骨骼数量、顺序与名称；不匹配时停止恢复。
4. “从 FBX 恢复网格”需 5 秒内二次确认。它恢复 FBX 自带网格、形态键和默认权重，清空草稿，建立新的初始恢复基准；已生成文件保留，本次输出仍可继续覆盖。目标骨骼引用保持原样，支持 Undo。
5. 本工具不会自动搜索整盘或下载缺失模型；找不到 FBX 时请手动指定或重新导入原文件。

## 预览模型2

从主工具“预览”区域点击 **预览模型2**，打开普通 Unity 编辑器窗口，支持停靠或独立摆放；拖入另一个普通场景实例的 SkinnedMeshRenderer。

- 只临时调整形态键权重，不提供改名、删除、生成或保存网格功能。
- 可搜索名称、拖动预览滑条；**点击形态键名称直接复制**，不再提供独立复制按钮。
- 与主工具相同，每 20 项一组折叠，默认展开第一组，支持全部展开 / 折叠；搜索自动展开匹配组，清空搜索恢复原折叠状态。分组不改变形态键或默认数值。
- “恢复拖入时数值”恢复该窗口绑定对象时记录的权重；“全部归零”将所有形态键预览值设为 0，包括搜索隐藏的项目。
- 勾选“启用同步”后，主工具需先手动解锁预览。两窗口按完全相同的形态键名称同步，支持在任一窗口拖动；无同名项保持各自数值。模型2的归零 / 默认按钮也会同步同名项。
- 同步还包含操作位置：从任一窗口点击或调整形态键预览滑条，另一窗口会展开同名项所在组、滚动到该行并高亮。若搜索条件隐藏了该项，会清除该窗口的搜索条件；定位不会切换键盘焦点或中断当前滑条拖动，缺少同名项时不跳转。
- 主工具锁定预览后暂停同步，不会自动创建预览网格；模型2仍可独立预览。
- 两窗口不能同时操作同一个 Renderer。模型2若转为主工具目标，会先恢复其原始预览权重并清空模型2引用。
- 关闭模型2、切换目标、保存场景、进入运行或脚本重编译时恢复模型2拖入时的权重。关闭后清空引用，重开需要重新拖入。

## 注意事项

- 删除、改名不会自动改写动画、Descriptor、VRCFury、MA 或其他组件中的名称 / 索引引用。
- 折叠组不改变选择、混合配方、生成顺序及输出形态键数量。
- 本工具不包含游戏运行时形态键同步 / 动画重定向、排序、左右拆分、烘焙基础形状、批量编辑多个 Renderer 。
- 仅在 Editor 目录编译，专用 asmdef 与 `#if UNITY_EDITOR` 隔离，不安装运行脚本；运行模式禁用编辑。

版本 **1.6.1**。脚本注释、窗口、README 与 CHANGELOG 同步；运行资源名称保持稳定。
